# Ashrith — Developer Portfolio

A responsive dark-premium React portfolio built with Vite.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Before publishing
Update these placeholders in `src/main.jsx`:
- `YOUR_EMAIL@example.com` with your professional email.
- LinkedIn and GitHub links with your profile URLs.
- Add real repository links when you are ready to showcase public code.
- Confirm the graduation year shown in the About section.
- Update internship responsibilities as you complete them.

## Build for deployment
Run `npm run build`. The production site is generated in `dist/`.

You can deploy the `dist/` folder using Vercel, Netlify, or another static hosting provider.
