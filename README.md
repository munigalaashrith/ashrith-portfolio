# Ashrith — Developer Portfolio

A responsive dark-premium React portfolio built with Vite, including smooth scrolling, scroll progress, reveal-on-scroll motion and a back-to-top control.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Build for deployment
Run `npm run build`. The production site is generated in `dist/`.

You can deploy the `dist/` folder using Vercel, Netlify, or another static hosting provider.
